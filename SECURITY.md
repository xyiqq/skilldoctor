# Security / 安全

## English

skilldoctor is a static checker. It does not execute skills, download remote skill packs, or send skill contents to a network service.

If you find a bypass in `audit` rules, open a GitHub issue with a **synthetic** fixture. Do not attach a real private key, token, or customer skill.

If a published release ever shipped a real secret, revoke that secret first, then open an issue.

## 中文

skilldoctor 是静态检查器。它不会执行 Skill、不会下载远程 Skill 包、也不会把 Skill 内容发到网络服务。

如果你发现 `audit` 规则可被绕过，请用**合成**样例开 GitHub issue。不要附上真实私钥、令牌或客户 Skill。

如果某个已发布版本里出现了真实密钥，先吊销该密钥，再开 issue。
